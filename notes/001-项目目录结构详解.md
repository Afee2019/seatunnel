> 文档编号: 001
> 生成日期: 2025-12-28
> 项目版本: 2.3.13-SNAPSHOT

## 一、项目概述

Apache SeaTunnel 是一个分布式、高性能的数据集成工具，支持批处理和流处理数据同步。支持多种执行引擎：SeaTunnel Zeta Engine（原生引擎）、Apache Flink 和 Apache Spark。

### 4.1 seatunnel-api - 核心 API 模块
**用途**: 定义 Connector V2 API，包括 Source、Sink、Transform 接口和表/目录抽象

```
seatunnel-api/src/main/java/org/apache/seatunnel/api/
├── annotation/           # 注解定义（如配置项注解）
├── common/              # 公共类
│   └── metrics/         # 指标定义
├── configuration/       # 配置管理
│   └── util/            # 配置工具类
├── env/                 # 执行环境抽象
├── event/               # 事件系统
├── metalake/            # 元数据湖集成
├── options/             # 配置选项
│   └── table/           # 表选项
├── serialization/       # 序列化接口
├── sink/                # Sink（数据写入）API
│   ├── event/           # Sink 事件
│   └── multitablesink/  # 多表 Sink
├── source/              # Source（数据读取）API
│   └── event/           # Source 事件
├── state/               # 状态管理
├── table/               # 表抽象
│   ├── catalog/         # Catalog 接口
│   │   ├── exception/   # Catalog 异常
│   │   └── schema/      # Schema 定义
│   ├── connector/       # 表连接器
│   ├── converter/       # 类型转换器
│   ├── coordinator/     # 协调器
│   ├── factory/         # 工厂模式接口（SPI入口）
│   ├── schema/          # Schema 相关
│   │   ├── event/       # Schema 变更事件
│   │   ├── exception/   # Schema 异常
│   │   └── handler/     # Schema 处理器
│   └── type/            # 数据类型定义
├── tracing/             # 链路追踪
└── transform/           # Transform 接口
```

**关键接口**:
- `SeaTunnelSource`: 数据源接口
- `SeaTunnelSink`: 数据写入接口
- `TableSourceFactory`/`TableSinkFactory`: SPI 工厂接口

## 五、作业配置结构

SeaTunnel 作业使用 HOCON 格式配置:

```hocon
env {
  parallelism = 2
  job.mode = "BATCH"  # 或 "STREAMING"
  checkpoint.interval = 5000
}

source {
  # 数据源配置
  SourceName {
    plugin_output = "source_table"
    # 源特定配置...
  }
}

transform {
  # 可选的数据转换
  TransformName {
    plugin_input = "source_table"
    plugin_output = "transform_table"
    # 转换配置...
  }
}

sink {
  # 数据目标配置
  SinkName {
    plugin_input = "transform_table"
    # 目标特定配置...
  }
}
```

## 六、开发相关

### 6.1 构建命令
```bash
# 完整构建
./mvnw clean install -DskipTests

# 构建发布包
./mvnw clean package -pl seatunnel-dist -am -Dmaven.test.skip=true

# 代码格式化
./mvnw spotless:apply

# 运行测试
./mvnw test                          # 单元测试
./mvnw verify -DskipUT=true -DskipIT=false  # 集成测试
```

- Scala 2.12
